## Project Structure / --jeremy

We can create new projects using the `--jeremy` flag:

<pre>
<code class="language-bash">$ roda-project --jeremy</code>
</pre>

This way, `roda-project` will download via git and use the <a href="https://github.com/jeremyevans/roda-sequel-stack" target="_blank">roda-sequel-stack</a> template created by Jeremy Evans.

This template is independent of `roda-project` and does not include `bin/roda`. You can see details on how to use it in the template's README.md.
